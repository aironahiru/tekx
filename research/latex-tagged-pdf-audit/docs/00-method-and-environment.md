## Evidence tags used in every layer document

| Tag | Meaning |
|---|---|
| **[S]** | Read in source code or official documentation; the file or document is named |
| **[R]** | Reproduced in this audit; raw output under `evidence/`, regenerated by `tools/run-audit.sh` |
| **[U]** | Under-documented runtime detail: no primary source located, or behaviour of closed-source software not observable here |

## Procedure

1. **Source extraction.** Read key definitions (`\keys_define:nn`), hook/socket declarations, Lua callback registrations and module manifests directly from `.dtx`/`.lua`/`.ltx` sources rather than secondary descriptions.
2. **Release notes.** LaTeX News issues 40–44 (Nov 2024 – Nov 2026), Tagged-PDF sections, as the authoritative changelog.
3. **Compilation.** Every configuration in `examples/` compiled with the audited TeX Live; pass counts recorded.
4. **Validation.** veraPDF with the PDF/UA-2 (+ ISO/TS 32005), WTPDF 1.0 Accessibility and PDF/A-4f profiles. Failure clauses quoted from veraPDF output, so clause numbering comes from the validator's profile and not from memory.
5. **Object inspection.** pikepdf dump of Catalog, StructTreeRoot, namespaces, RoleMapNS, ClassMap, content-stream operators, fonts, associated files and XMP.
6. **Consumer probing.** poppler and pdf.js on the same files, plus reading pdf.js and PDFium source for the code paths behind the observed behaviour.
7. **Link verification.** Every URL in the "Verified primary sources" tables was fetched (HTTP status recorded) or verified with `git ls-remote`. Hosts that refuse automated access (pdfa.org, iso.org: HTTP 403) are listed as "cited by primary source; not fetched".

## Limits

- Benchmarks are single-machine (4 CPU threads, cloud container) medians of 3 runs; use them as relative, not absolute, numbers.
- Closed-source consumers (Acrobat, Foxit releases, Chrome's internal use of PDFium, JAWS) were not executed. Statements about them are sourced quotes or marked **[U]**.
- The ISO standards themselves were not available as text. ISO 14289-2:2024 and ISO/TS 32005:2023 clauses are quoted from veraPDF's machine-readable profile; ISO 32000-2:2020 clause numbers appear only where that profile cites them; ISO 32000-1:2008 numbering was read from the Adobe-hosted copy.

## Reproduce

```bash
VERAPDF=/path/to/verapdf TEXBIN=/path/to/texlive/2026/bin/x86_64-linux \
PDFJS=/path/to/node_modules/pdfjs-dist tools/run-audit.sh
```

Additional TeX Live packages needed beyond `collection-latex`, `collection-latexrecommended`, `collection-luatex`, `collection-fontsrecommended`:

```bash
tlmgr install latex-tagging-status mwe soul ulem multirow caption enumitem hyperxmp
```

veraPDF headless install (IzPack auto-install file):

```bash
java -jar verapdf-izpack-installer-1.30.3.jar tools/verapdf-auto-install.xml
```
